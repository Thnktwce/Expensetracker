# Expense Tracker

Cross-platform personal finance app built with **.NET MAUI** (C#, XAML).

## Features
- Add and list expenses and incomes
- Expense categories
- Charts of spending
- Settings page
- Runs on Android, Windows and macOS (Mac Catalyst)

## Structure
```
Models/   Expense, Income, Category
Pages/    Main, Expenses, Incomes, Add*, Charts, Settings
Platforms/   platform-specific code
```

## How to run
1. Install Visual Studio 2022 with the **.NET MAUI** workload.
2. Open `Expensetracker.sln`.
3. Choose a target (Android emulator or Windows Machine) and run.
